

# 🌤️ SkyFetch Weather Dashboard

A responsive weather dashboard built with **HTML, CSS, and JavaScript** using the **OpenWeatherMap API**.
The app allows users to search for cities, view current weather, explore a 5-day forecast, and save recent searches with automatic reload on refresh.



---

## ✨ Features

* 🔍 Search weather by city
* 🌡 View current temperature & weather details
* 📅 5-day forecast display
* 💾 Save recent searches (max 5)
* 🔁 Auto-load last searched city
* 🧹 Clear search history
* 📱 Fully responsive design
* 🚀 Deployed on Vercel



## 🛠 Tech Used

* HTML
* CSS (Responsive Design)
* JavaScript (OOP, Async/Await, Promises)
* localStorage API
* OpenWeatherMap API
* Git & Vercel Deployment



## 📂 Project Structure

```
skyfetch-weather-dashboard/
```

## 🚀 How to Run

1. Open `index.html` in your browser
2. Search for any city
3. View weather & forecast
